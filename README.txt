AUBI FASHIONS WEBSITE
======================

Files:
- index.html   Main website
- style.css    Design and responsive layout
- script.js    Menu + current year
- assets/      Aubi flyer image

HOW TO VIEW:
1. Open this folder.
2. Double-click index.html.
3. It will open in Chrome.
4. The website works without a server.

HOW TO EDIT:
- Change wording in index.html.
- Change colours/layout in style.css.
- Replace assets/aubi-flyer.jpg if Aubi provides a better image.
